# Aurora Core — Beta Test Scenarios

These scenarios validate the core functionality of Aurora Core.

## 1. Login Flow
- Navigate to the dashboard
- Log in using mock credentials
- Confirm redirect to Home

## 2. Device Onboarding
- Add a new TurnBot Mini
- Edit metadata
- Trigger a simulated alert

## 3. Agent Creation
- Create a new Agent
- Run an LLM query
- Review activity logs

## 4. Monte Carlo Simulation
- Open Simulation module
- Run a 1,000-run simulation
- Export results

## 5. Alerts System
- Trigger a device alert
- Acknowledge it
- Confirm it clears

## 6. Settings + Profile
- Update profile fields
- Toggle theme

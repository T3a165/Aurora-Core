# Aurora Core — v0.9.0-beta (Aurora Dawn)
Welcome to the closed beta of Aurora Core, the unified control, simulation, and intelligence platform for TurnBot devices.

This beta is intended for internal testers, early evaluators, and engineering partners.  
It includes all core modules, device management, agent architecture, simulation tools, and the LLM interface.

## What’s Included
- Full Aurora Dashboard (React 19)
- TurnBot Mini / Pro / Hub device models
- Device onboarding + metadata editing
- Agent creation + activity logs
- Monte Carlo simulation engine
- LLM interface (mocked)
- Alerts + notifications
- Auto-seeded demo data
- Mock OAuth login

## What’s Not Included
- Real Manus OAuth
- Real hardware integration
- Mobile layout
- Multi-tenant support
- Firmware sync
